## Acceptance test before using in every video

1. Generate each pose as a separate image with the same canonical reference, then animate short adjacent still/keyframe transitions; do not invent hand-drawn or rigged motion if only generated images were used. Check hat, hands, eye shape and lens circumference frame by frame for morphing.
2. Record the approved line separately, measure its real length and align Vale's lips/gestures to syllables. If it runs long, reduce words *before* changing speed; never cut narration or slow the visual into an intro that consumes the story.
3. Verify all exact letters, name/handle status, phone-scale readability, centered UI-safe positioning, continuity with the hook and next scene, clean 30 fps, no borrowed references and no music. Only after the user selects/approves a variant and Studio accepts the matching handle should the name be treated as final or any live channel assets updated.
