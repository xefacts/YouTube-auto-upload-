# UNCASE — private Short documentary + editable source

**Story:** The 1911 Mona Lisa theft, Vincenzo Peruggia, the Florence recovery and the 1914 sentence. This is a documented theft conviction, not an unsolved-murder case; the film examines the disputed motive. No fabricated “solution” or named accomplices.

- Final review video: `UNCASE_MONA_LISA_THEFT_PRIVATE_REVIEW_1080x1920.mp4` — 67.3 s, vertical 1080×1920, 30 fps, H.264 / 48 kHz stereo AAC.
- Narration and sound design: `assets/narration.wav`, `assets/sound_design.wav`, exact utterance timing JSON.
- Script, evidence notes and institutional source links: `SCRIPT_AND_SOURCES.md`.
- Copy-ready YouTube episode description with sources: `YOUTUBE_DESCRIPTION.txt`.
- Phrase-timed captions: `CAPTIONS_APPROX_WORD_TIMED.srt` (approximate phrase alignment; review while listening).
- Renderer: `render_short.py`; voice generation: `narration.py`; procedural audio: `build_sound_design.py`.
- The source kit ZIP includes the final MP4, all generated illustration plates, rendered audio, code, fonts/license notices, caption file, sources, and reusable creator skill guides/topic finder. The Apache Kokoro ONNX weights are optional and downloaded separately by setup script; model SHA in setup is verified.

**Important:** all image scenes carry a persistent on-screen “ILLUSTRATIVE RECONSTRUCTION” label. This 2D/2.5D film uses pan/zoom/parallax camera simulation, not full 3D character animation. Voice is free, offline Kokoro synthesis; not ElevenLabs and not a cloned voice. Review for story, voice, captions and fact-check before any future publishing; nothing was uploaded to YouTube.
