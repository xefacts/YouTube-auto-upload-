4. **Script before visuals:** map a ~25–40 second Short to hook (0–3s), curiosity gap (~3–10s), escalating beats, and a truthful satisfying/loop-friendly ending. Speak-test the actual word count and timing; no cut-off sentence just to force a loop. Include scene/character-expression cues every ~3–4 seconds.
5. **Visual storyboard:** vertical 9:16 for Shorts unless the user explicitly requests another format; use independently created historical backgrounds and original character assets. Plan distinct expressions/gestures/poses (not a single rigid character sliding across a background). If motion is created from a sequence of generated still poses, describe it honestly; don't call it hand-rigged animation. Plan parallax and purposeful slide reveals, not a default repetitive zoom.
6. **Captions/type:** for the new channel, design single-word or short-phrase emphasis in bold ivory/lime with strong contrast, timed to speech. Use a readable condensed headline + a neutral sans for support. Avoid full-screen subtitle spam, long paragraphs, flicker and busy backgrounds behind type. Keep captions inside actual Shorts UI safe areas, test a phone-sized crop, and check the caption timing against audio. This is distinct from the old Emu Phase 3 caption treatment the user rejected.
7. **Voice and sound:** choose an original, consistent US-English narrator; do not imitate reference voices. Preserve the user's prior no-music preference until explicitly revised; use restrained original non-melodic foley where appropriate, never call it authentic field audio. Match effects to actions without burying speech.
8. **QC before sharing:** audit facts against evidence, pose changes, caption legibility, sound mix, spelling, device crops, aspect ratio, frame count, exact runtime, and no borrowed reference footage/audio. Label illustrated reconstructions. Deliver a private preview for approval.
9. **Publishing gate:** do **not** upload, schedule, edit a live channel, or change workflows/credentials without the user's fresh explicit approval for that specific channel/action. A Drive review link is not a YouTube upload.
