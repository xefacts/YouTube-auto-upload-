# Skill 03 — Human-sounding Shorts with ethical retention

## 45–75 second structure (adjust to evidence; never force a loop)
- **0–2s — specific hook:** a date, object, decision or contradiction; no generic “Did you know?”
- **2–10s — promise + curiosity gap:** state the one question the piece will answer.
- **10–25s — context and first clue:** introduce only essential names; explain how the clue matters.
- **25–40s — turn:** evidence, decision or failed assumption changes the direction. Refresh viewer curiosity with a new meaningful question.
- **Around midpoint — viewer question:** invite interpretation (“What would you infer from this?”), then answer from record. Do not imply the audience can solve an active case from a few facts.
- **Final 15–20s — evidence-led payoff:** tell outcome/sentence only if verified; clearly name any unresolved issue. End with a relevant question, not an unsupported culprit reveal.

## Human rhythm
Write aloud. Prefer concrete nouns and active verbs. Vary sentence length; use silence around an important clue. Each sentence should advance evidence, context or emotional understanding. Remove stock phrases (“dark secrets”, “you won’t believe”), duplicated hooks, inflated stakes and AI-style recap.

## Attention design, not manipulation
Open loops must be paid off. Use transitions at real changes in evidence, not arbitrary rapid cuts. Include a new factual or visual beat around each 7–12 seconds, but do not manufacture a clue merely to meet a timer. No false countdowns, guilt-bait, overclaiming, or “the truth they hid” without evidence.

## Short script gate
One central question; no more than 3–5 names; spoken word count tested against actual VO; include an evidence/uncertainty line; question is answered; final line is not chopped; sources support every assertion. For 60 seconds, start near 125–155 words and time the actual read.
